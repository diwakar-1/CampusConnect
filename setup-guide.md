# CampusConnect – Complete Setup & Installation Guide
**CGC University Mohali – College Event Management and Registration System**

---

## 1. Prerequisites Checklist

Ensure the following tools are installed on your machine:

1. **Java Development Kit (JDK 21 or later)**
   - Verify in terminal: `java -version`
   - Set `JAVA_HOME` environment variable pointing to your JDK directory (e.g. `C:\Program Files\Java\jdk-21` or `jdk-26`).

2. **MySQL Server 8.0+**
   - MySQL 8 service should be running on port `3306`.
   - Verify connection via MySQL Workbench or command line: `mysql -u root -p`.

3. **IntelliJ IDEA (Recommended) / VS Code / Eclipse**
   - IntelliJ IDEA Community or Ultimate edition has built-in Maven and Spring support.

4. **Web Browser**
   - Google Chrome, Microsoft Edge, Mozilla Firefox, or Safari.

---

## 2. Database Setup (MySQL 8)

### Step 1: Open MySQL Command Line or MySQL Workbench
Log in as `root`:
```sql
mysql -u root -p
```

### Step 2: Create the Database
Execute the following SQL command:
```sql
CREATE DATABASE IF NOT EXISTS campus_connect CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

*(Note: The database tables, constraints, foreign keys, and initial seed data are automatically generated by Hibernate and the built-in `DataInitializer` upon the first startup. Optionally, you can also run `schema.sql` and `data.sql` manually).*

---

## 3. Project Configuration

Open `src/main/resources/application-mysql.yml` and adjust your MySQL password if it differs from the default `root`:

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/campus_connect?createDatabaseIfNotExist=true&useSSL=false&allowPublicKeyRetrieval=true&serverTimezone=Asia/Kolkata
    username: root
    password: YOUR_MYSQL_ROOT_PASSWORD
    driver-class-name: com.mysql.cj.jdbc.Driver
  jpa:
    hibernate:
      ddl-auto: update
```

### Optional: In-Memory H2 Mode (Instant Run Without MySQL)
If you wish to test or run the application immediately without running a MySQL server, switch the active profile to `h2` in `src/main/resources/application.yml`:
```yaml
spring:
  profiles:
    active: h2
```
Or start the application with `-Dspring.profiles.active=h2`.

## 4. How to Run in IntelliJ IDEA

1. Launch **IntelliJ IDEA**.
2. Click **File -> Open...** and select the project folder:
   `Campus Connect`
3. IntelliJ will detect `pom.xml` and resolve all Maven dependencies automatically (Spring Boot 3, ZXing, OpenPDF, Thymeleaf).
4. Navigate to:
   `src/main/java/com/campusconnect/CampusConnectApplication.java`
5. Right-click the file and click **Run 'CampusConnectApplication'** (or press `Shift + F10`).
6. Once the console prints:
   `Started CampusConnectApplication in X.XXX seconds`, open your browser at:
   **http://localhost:8080**

---

## 5. How to Run via Command Line

Open PowerShell or Command Prompt inside the project directory:

```powershell
# Using installed Maven
mvn spring-boot:run

# Or package into a runnable JAR
mvn clean package -DskipTests
java -jar target/campus-connect-1.0.0-SNAPSHOT.jar
```

## 8. Troubleshooting

- **Port 8080 already in use**:
  Change `server.port: 8081` in `src/main/resources/application.yml`.
- **MySQL Access Denied**:
  Verify your root password in `application-mysql.yml` or run in H2 profile mode.
- **Email Dispatching**:
  `EmailService` is configured with graceful fallback logging, so if SMTP is not configured, email notifications are logged to the console without interrupting any user actions.
